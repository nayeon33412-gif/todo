## 실행

`index.html`을 브라우저로 열면 됩니다.

```sh
open index.html
```

## 기능

- 할 일 추가, 완료 체크, 삭제
- 수정: 제목을 더블클릭하거나 ✎ 버튼을 누릅니다. Enter로 저장, Esc로 취소하며, 내용을 비우면 삭제됩니다.
- 필터: 전체 / 진행 중 / 완료 (`#/active`처럼 주소에 반영되어 새로고침해도 유지)
- 완료 항목 한 번에 삭제, 남은 개수 표시
- 브라우저 `localStorage`에 자동 저장, 여러 탭 사이 동기화
- 다크 모드, 모바일 화면, 키보드 조작, 한글 입력(IME) 지원

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면 구조 |
| `style.css` | 스타일 (라이트/다크 테마) |
| `app.js` | 상태 관리, 렌더링, 저장 |

데이터는 사용 중인 브라우저에만 저장되므로 다른 브라우저나 기기와는 공유되지 않습니다.
